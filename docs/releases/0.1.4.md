# work-fold 0.1.4

August 1, 2026

work-fold 0.1.4 is the first public build after the internal 0.1.2 and 0.1.3
qualification candidates. It ships the new first-run welcome, hardens the
truthfulness of Chat and Checks, and gives the Mac release lane a faster,
resumable path from interactive candidate to signed public artifacts.

## Highlights

- The first-run screen now teaches the product where it actually lives: a
  composed menu-bar scene shows the fold, the drop target, the instruction
  field, and the fact that work continues after the main window closes. The
  work-fold identity now separates that explanation from the two folder-first
  setup actions.
- Dark is the intentional default for a fresh profile. The onboarding scene is
  also verified in light, dark, reduced-motion, and forced-colour modes.
- A stopped turn with no persisted Assistant reply can no longer donate its
  live thinking or activity recap to the preceding reply. Completed and
  interrupted replies still keep the artifacts that actually belong to them.
- Provider, setup, timeout, and general Assistant failures now leave a durable,
  typed, sanitized result in the Chat instead of exposing host diagnostics or
  making an older response look current.
- Checks pause cleanly around Space creation, registration, rename, and removal,
  retry stale conflicts honestly, and continue to inspect only explicitly
  designated targets. Manual History restore points now say when the current
  files already match the latest point instead of claiming a new one was made.
- The renderer refreshes Space state when the app returns to the foreground,
  so files and work completed outside the active view appear without requiring
  a relaunch.
- macOS release work now has a Developer ID-signed app-only candidate for fast
  packaged QA, timed source-bound checkpoints for complete distributions, safe
  resume/status commands, and an unchanged strict verification and draft-first
  publication boundary.

## Walkthrough

The release walkthrough is now illustrated in the main
[README](../../README.md#a-quick-walkthrough): an ordinary-folder Space with a
grounded Assistant result, a fresh bounded Check, and the real menu-bar popover
running above the installed app.

## Mac distribution

The Apple silicon app and DMG are Developer ID-signed by Team `464JD5K8DC`,
notarized by Apple, stapled, and accepted by Gatekeeper. The separate Mac feed
contains the DMG, updater ZIP, both blockmaps, `latest-mac.yml`, checksums, and
the machine-readable and human-readable release manifests from one verified
build.

This is an explicit Mac-first release. Windows signing and publication are
deferred; no unsigned Windows installer is presented as a public release.

- Desktop preparation, Electron sandbox smoke, packaged assets, signing,
