# work-fold 0.3.3

August 13, 2026

work-fold 0.3.3 makes long-running Assistant work substantially harder to
lose, and gives the macOS app and menu bar their finished production icons.

## Assistant turns survive interruption

- Accepted turns now receive a durable identity before execution. Retried
  requests reuse that acceptance instead of accidentally starting duplicate
  work.
- Streaming progress is checkpointed while a turn runs. If a provider stops
  responding, work-fold preserves the partial response, records the
  interruption, and leaves the Chat ready to continue.
- A restart repairs unfinished turn records without silently rerunning work.
  An accepted message that never reached its transcript can be resumed only
  through an explicit retry using the same request identity.
- Chat event streams retain a bounded replay window, allowing a renderer or
  menu-bar fold that reconnects to reconcile the events it missed.
- The main Chat and menu-bar fold use the same durable task state, so switching
  surfaces or recovering the renderer does not make accepted work disappear.

## Native macOS artwork

- The Dock and application bundle now use the supplied Apple Icon Composer
  Default export. The complete PNG size ladder and ICNS are generated
  deterministically from that committed source.
- The menu-bar template was rebuilt at native 18-point and Retina 36-point
  sizes with preserved proportions and three distinct faces. macOS continues
  to tint it automatically for light and dark menu bars.
- Packaging tests verify the ICNS structure, exact application source, template
  geometry, monochrome pixels, and bundled assets.

## Safety and compatibility

- Turn records live in machine-local application state; portable Space
  transcripts remain the content authority. Provider credentials, tokens, and
  signing material are not included in the journal.
- The journal is bounded, compacts atomically, repairs only a truncated final
  write, and preserves file-level durability on both macOS and Windows.
- Packaging dependencies now use Electron's maintained safe ZIP extractor and
  patched Nanoid and PostCSS releases; the release audit reports no known
  vulnerabilities.
- This is an in-place work-fold update. It does not read, migrate, or modify
  legacy Workspace application state or `.workspace/` metadata.

## Current limitations

- Public Windows publication remains unavailable until the repository has its
  dedicated Windows signing credentials. The macOS release uses the documented
  Mac-first exception; its signed, notarized artifacts are published through
  the separate `Mat-Tom-Son/work-fold-mac-releases` feed.
- The macOS updater still publishes Apple-silicon (`arm64`) artifacts only.

## Verification

- Windows Electron Builder package smoke in GitHub Actions.
- macOS Developer ID signing, hardened runtime, Apple notarization and
