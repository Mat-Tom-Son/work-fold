# Workspace 0.4.12

Workspace 0.4.12 gives Chat history’s **Other Spaces** section a cleaner,
better-aligned Space identity treatment.

## Cleaner cross-Space Chat groups

- The compact Space glyph is centered in a fixed 18-pixel slot.
- The inherited colored tile, outline, rounded container, and shadow are
  removed in both light and dark themes.
- Current-Space headings, Chat tabs, and customized Space identities keep
  their existing visual treatment.
- A UI contract protects the compact glyph from accidentally inheriting the
  generic identity tile again.

## Upgrade notes

This is an in-place update. Registered Spaces, named Chats, ordinary files,
Library materials, History, Pi resources, provider setup, appearance settings,
restricted apps, grants, saved connections, automations, open tabs, and
App-platform state are preserved.

## Release verification posture

Public release completion requires the exact pushed `v0.4.12` commit to pass
Node 24 TypeScript checks, the full test suite, dependency audit, desktop
preparation, the canonical Electron Builder package smoke, the Windows release
workflow, and the guarded Developer ID-signed, notarized, and stapled macOS
publication lane. The installed 0.4.11 macOS app must discover and apply 0.4.12
through the visible frontend updater. Installed-app verification must confirm
that the Other Spaces glyph is transparent and centered, and that the durable
Chat title created during the 0.4.11 smoke remains named across Chat switches
and a full quit and cold reopen.
