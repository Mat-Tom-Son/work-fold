# Workspace 0.4.2

Workspace 0.4.2 is a performance, search, and reliability release. It makes
large Spaces and long Chat histories cheaper to browse, adds content search
where people expect it, and hardens the recovery and restricted-app boundaries
behind those quality-of-life improvements.

## Find work by what it says

- Files search now includes bounded matches inside ordinary text files, with
  paths, line numbers, previews, truncation disclosure, and one-click opening.
- Chats search now includes bounded transcript matches across registered Spaces,
  while respecting the selected Active, Snoozed, or Archived view.
- Cross-Space Chat search isolates unavailable folders: matches from reachable
  Spaces remain usable and the partial result is stated plainly.
- Superseded searches are cancelled through the renderer, local API, and disk
  walk instead of leaving stale scans running after the query changes.
- File and Chat previews are normalized without losing the location of the
  matching text, and title/lifecycle bookkeeping is excluded from transcript
  results.

## Faster large-Space navigation

- Chat-list summaries use a machine-local derived index and rebuild when file
  change identity shows that an ordinary transcript was externally replaced.
- Space-tree inspection uses bounded filesystem concurrency, a deterministic
  folders-first order, a whole-walk entry budget, and explicit partial-list
  state.
- Ignored items no longer consume the visible tree budget, and lazy folder
  loads carry truncation state back to the Files toolbar.
- History restore keeps memory bounded and stages verified content before it
  mutates the Space, so checkpoint pruning cannot remove bytes midway through a
  restore.

## Security and correctness hardening

- Every History capture hashes current bytes. Size and modification time are
  never treated as proof of backup identity, because ordinary sync and archive
  tools can preserve both while replacing content.
- Restricted-app public `GET` requests can fall back across already-approved
  DNS addresses, while mutating requests never replay after an ambiguous
  connection failure.
- Reviewed request headers now reject the full `x-forwarded-*` family and other
  routing, proxy, hop-by-hop, and credential-bearing names.
- The reproducible dependency graph pins Pi's shrinkwrapped
  `brace-expansion` and `protobufjs` copies to reviewed fixed versions; a clean
  install and `npm audit` report no known vulnerabilities.
- Renderer behavior tests run in a real DOM and now cover search cancellation,
  partial results, file opening, modal focus containment, and background
  isolation without React test warnings.

## Upgrade notes

This is an in-place update. Registered Spaces, ordinary files, Chats, Library
materials, History, Pi resources, provider settings, restricted apps, grants,
connections, automations, and App-platform state are preserved.

The Chat summary index is derived machine-local data. Workspace 0.4.2 rebuilds
older index records automatically from portable transcripts; no user action or
content migration is required.

## Release verification posture

This document describes the 0.4.2 release candidate. Public release completion
requires the exact pushed `v0.4.2` commit to pass Node 24 TypeScript checks, the
full test suite, clean-install and dependency audits, desktop preparation and
preflight, Windows installer/updater verification, and the guarded Developer
ID-signed and notarized macOS publication lane. The installed 0.4.1 macOS app
must then discover and apply 0.4.2 through its visible frontend updater button,
relaunch, pass installed-bundle verification, and survive a full quit and cold
reopen before the end-to-end update is considered verified.
