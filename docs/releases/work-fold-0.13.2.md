# work-fold 0.13.2

October 27, 2026

A clearer place to start a Chat, attach your files, and find what your Worker made.

- **A more useful New Chat screen.** The message box sits just below the greeting, with your three most recent active Chats underneath.
- **Easier file attachments.** Use the new **+** button to search files in your work-folder or choose files from your computer. Files from your computer are copied into the dated `Dropped/` folder before they are attached. The picker refreshes when reopened, and menus stay within the Chat panel.
- **A smaller, simpler message box.** It starts one line tall and grows as you type. Model and reasoning choices now share one menu.
- **Open the files from a reply.** Files the Worker saved or edited appear at the end of its response, with a button to open each one. This list covers file-writing and editing tools; changes made through commands may not appear.
- **Clearer work-folder headers.** Picture banners put the name and switching arrow on a readable frosted pill. Headers shrink while you scroll long lists and return at the top.
- **Small readability fixes.** Markdown line breaks no longer add unwanted blank lines. The open Chat stands out in the list, and long file names keep their extensions visible.
- **Updated dependencies.** Includes security fixes for networking, image processing, shell quoting, and development tooling.
