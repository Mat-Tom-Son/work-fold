# work-fold 0.13.8

November 5, 2026

This release makes the interface more consistent and adds a few tab and banner options.

- Text, buttons, and search fields use one set of sizes. Muted text is easier to read in every theme, and labels, menus, and buttons use Title Case.
- Each file opens in its own tab. Two open files with the same name show their folder.
- The tab menu adds **Close Tabs to the Right** and **Reopen Closed Tab**. ⌘⇧T reopens any closed tab.
- Customize work-folder offers four banner layouts: Card, Compact, Band, and Cover.
- Chats groups older Chats by date.
- In a Chat, task lists show checkboxes, plain-text blocks wrap, and the context meter fills as a small pie.
- Compare reads as a list of changes, every Settings page opens with its title, and Skills & Extensions and Settings → Apps use plainer labels.

Mac releases and automatic updates are available through the
[work-fold Mac release feed](https://github.com/Mat-Tom-Son/work-fold-mac-releases/releases).
