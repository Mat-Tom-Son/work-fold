# work-fold 0.4.25

September 11, 2026

Assistants can now work together across Spaces, pass back selected results, ask
questions, and continue when an answer arrives. Progress follows the whole
request, including delegated work. Stop reaches its outstanding children too.

Questions appear where the work started: Space Chats, the fold, trusted App
requests, and your paired web fold. Answer them in place without finding another
Chat. Drafts survive reconnects and refreshes. If an answer was saved but its
follow-up could not start, you can read the saved answer and continue it once.

Results name partial outcomes and offer direct links to the files the Assistant
selected. Apps show completed summaries and files immediately, with technical
details available on demand. Automatic follow-ups appear as quiet activity.

Actions run when requested and leave receipts. Deleted content is recoverable
through History or Recently deleted. New App installations receive their declared
powers; eligible connections, automation settings, receipts and explicit
revocations survive updates. Secrets remain on trusted setup surfaces.

Apps can request Assistant work directly, make bounded model calls without tools
or a Chat transcript, and observe changes to their own tasks, Checks and granted
files. The CLI shares the collaboration verbs and durable results. Restart
reconciles saved work without automatically replaying actions.

This release also improves slow-connection recovery and file navigation, and
updates the YAML parser and image tooling to patched dependency versions.
Spaces remain ordinary folders. Existing files, Chats and App data stay local;
request coordination records do not travel inside Space folders.

The paired web client requires your desktop online. Its detailed work controls
follow the request's original browser grant; public viewers and sandboxed App
views do not gain access to other conversations or questions.

Availability and downloads: [the Mac release feed](https://github.com/Mat-Tom-Son/work-fold-mac-releases/releases/latest).
