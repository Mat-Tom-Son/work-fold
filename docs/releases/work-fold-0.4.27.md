# work-fold 0.4.27

September 11, 2026

The menu-bar fold now has searchable chat history. Reopen an earlier Chat and
continue in that conversation, with its own model and work status. Switching
Chats keeps unsent drafts and attachments while the popover remains open, and
running work stays reachable from a compact background-work link.

Starting a new Chat opens a quiet draft without the old notice. Checks no
longer occupy the popover. On the web, questions appear in the Chat that owns
the work, with a small reminder in the chat list; the separate Needs you page
and its raw activity feed are gone.

Web Spaces now open as named workspaces with Files and Apps views. Browse
folders alongside an inline file preview, return to the Space list, or ask the
fold about a Space or file. These actions prepare a draft with an explicit
reference for you to send. The layout adapts to phones.

This release also protects chat selection from late refreshes and keeps replies
attached to the selected conversation when another surface starts a newer one.

The paired web fold still needs your desktop online. Existing Space files,
Chats, App data, and access boundaries remain intact.

Availability and downloads: [the Mac release feed](https://github.com/Mat-Tom-Son/work-fold-mac-releases/releases/latest).
