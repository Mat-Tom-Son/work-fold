# work-fold 0.4.32

September 12, 2026

Saved chat titles from older versions display again instead of being replaced
with New Chat. Automatic titles and manual renames persist for both the
work-fold agent and Folder workers, including after restart.

The menu-bar chat history now offers Rename and Delete in each chat's actions.
Web chat offers Delete beside its title. Deleted agent chats move to Recently
deleted with their titles and can be restored. Active or waiting work must be
finished or stopped before deletion. Retrying a completed web deletion does not
delete a restored chat again.

Downloads: [Mac release feed](https://github.com/Mat-Tom-Son/work-fold-mac-releases/releases/latest).
