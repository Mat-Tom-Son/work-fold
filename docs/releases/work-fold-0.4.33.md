# work-fold 0.4.33

September 23, 2026

This update makes everyday navigation, Chats, and file previews quieter and
easier to use.

- Choose the model for new Chats directly from the composer. Search the model
  list, see the Folder's saved choice first, and reach model settings from the
  picker. Existing Chats keep their session model.
- Recoverably delete a Folder Chat from its actions menu, undo immediately, or
  restore it from Recently deleted. Chats with running or unfinished work stay
  protected, and concurrent edits cannot recreate a deleted transcript.
- Use the compact file header to open files, choose another native application,
  reveal them in Finder, attach them to a Chat, or reach version history. Image
  and PDF previews load through the desktop's authenticated file service;
  Markdown renders in the file tab.
- Navigate crowded tab strips with wheel scrolling, edge fades, and an Open
  tabs list. Manage folders has a Done action and Escape support, and linked
  folders show compact locations.
- Reach Automations and Recently deleted directly in Settings. Closing the
  window now lives in Appearance. Mac shortcuts show native key symbols.
- Chat timestamps, context usage, commands, and Skills & Extensions cards show
  less incidental detail while keeping their actions available.
