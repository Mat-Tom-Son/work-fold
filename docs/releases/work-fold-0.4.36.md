# work-fold 0.4.36

September 26, 2026

This update makes tools, models, and app management easier to reach and gives
the desktop a calmer, more consistent layout.

- Open Skills & Extensions directly from the plus button in the navigation
  pane. Included tools have distinct icons, installed tools are grouped by
  where they live, and discovery and installation stay in one popup.
- Manage installed apps across your Folders in Settings → Apps. Open an app's
  build Chat, change the app, inspect it in App Studio, or open a Worker result
  in its owning Folder. The former desktop Library and Folder Apps tabs are
  retired; existing Library CLI commands remain available.
- Choose models in Settings → AI Models with a searchable, provider-grouped
  list and faster switching between Folder and work-fold agent settings.
  Older background responses can no longer replace a newly saved selection.
- Start a Chat or choose its model from the aligned split button. Folder
  actions are available from the Folder header's context menu, and Automation
  limits live with the rest of Automation settings.
- Enjoy more consistent labels, quieter tool controls, and improved composer
  and popup scrolling. Failed app-list loads no longer retry continuously,
  and opening an app's result file closes Settings so the file is visible.

Icon attribution and licenses are available in Settings → About → Icon Credits.
