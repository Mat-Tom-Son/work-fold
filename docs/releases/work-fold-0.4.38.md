# work-fold 0.4.38

September 29, 2026

This update adds Azure OpenAI setup using the deployments you have created
in Azure.

- Configure Azure in Settings → AI Models with your resource endpoint or
  Responses URL, API key, and deployment names. Enter multiple deployments
  separated by commas or new lines, then choose which one to use.
- Use your deployment names directly, including names outside Pi's built-in
  model catalog. No deployment mapping syntax is required.
- Share the saved Azure connection across this computer while choosing a
  model separately for each Folder's Worker and the work-fold agent.
- See clear validation and save feedback, including whether a connection
  has been tested. Keep a saved API key when updating deployment settings.
