# work-fold 0.4.40

September 30, 2026

This update gives Folder customization a dedicated popup and fixes clipped
selection highlights in the left rail.

- Customize a Folder in a popup with Banner, Icon, and Color tabs, paired light
  and dark previews, and a stable layout.
- Choose from four included banner images—Tide, Ember, Fold, and Dusk—or upload
  your own. Drag to frame an image or open **Adjust image** for position and zoom.
- Find icons through search and categories, and choose from a broader palette
  of labeled color presets. Pattern banners visibly follow the selected color.
- Open the Folder's model or instructions from the customization footer. A back
  arrow beside the Settings title returns to the same Folder and section.
- Keep left-rail selection and hover outlines fully visible.
- Update Electron within its current major version and refresh reviewed network
  and pattern-expansion dependencies for security fixes.

GitHub Actions is disabled in the source repository. Releases use the complete
local verification lane, signing, notarization, and artifact checks.

Downloads: [Mac release feed](https://github.com/Mat-Tom-Son/work-fold-mac-releases/releases/latest).
