# work-fold Linux preview 0.10.2

The sidebar toggle now sits immediately after **Help** in the application menu
strip. It follows the menu's layout as the window changes size, and still hides
or shows the navigation pane while keeping the rail available. The work-fold
agent controls remain on the right.

This is a small UI update to the Linux 0.10.1 preview, retaining its Mac 0.10.0
source baseline, Pi 1.1 runtime and Linux desktop integration. Quit work-fold
before installing the new DEB or RPM; existing work-folders and app data are
preserved. Linux previews have no automatic updates or production package
signatures. See [Linux builds](../linux-build.md) for setup and qualification
limits, including the separately distributed Chrome companion.
