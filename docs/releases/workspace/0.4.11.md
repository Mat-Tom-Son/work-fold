# Workspace 0.4.11

Workspace 0.4.11 makes Chat names durable and repairs old lists that could keep
showing completed conversations as **New Chat**.

## Stable automatic Chat titles

- A successful first Assistant turn now persists a generated Chat title based
  on the first user request instead of leaving naming as renderer-only state.
- Generated, placeholder, and manual title records are distinguished in the
  portable append-only transcript.
- A later manual rename always remains authoritative, including an intentional
  rename back to **New Chat**.
- Opening or switching Chats no longer lets the original placeholder replace a
  known generated title.

## Automatic stale-cache repair

- The machine-local conversation-summary index has a new semantic version, so
  old cached **New Chat** summaries rebuild from their intact transcripts on
  first listing.
- Cache-version regression coverage ensures later changes to title derivation
  cannot silently reuse an older interpretation.
- The transcript remains the source of truth; rebuilding the index never
  rewrites user messages or Assistant replies.

## Upgrade notes

This is an in-place update. Registered Spaces, named Chats, ordinary files,
Library materials, History, Pi resources, provider setup, appearance settings,
restricted apps, grants, saved connections, automations, open tabs, and
App-platform state are preserved.

## Release verification posture

Public release completion requires the exact pushed `v0.4.11` commit to pass
Node 24 TypeScript checks, the full test suite, dependency audit, desktop
preparation, the canonical Electron Builder package smoke, the Windows release
workflow, and the guarded Developer ID-signed, notarized, and stapled macOS
publication lane. The installed 0.4.10 macOS app must discover and apply 0.4.11
through the visible frontend updater, rebuild stale Chat summaries, persist a
generated title for a new real Assistant turn, pass installed-bundle
verification, and survive a full quit and cold reopen.
