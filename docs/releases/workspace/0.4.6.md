# Workspace 0.4.6

Workspace 0.4.6 keeps background Assistant work quiet. A Chat that acquires or
reconciles its persisted conversation identity no longer pulls focus away from
the Library, a file, Assistant tools, History, or an app tab.

## Quiet background continuity

- Starting an Assistant turn and switching to another work tab leaves that tab
  active while the Chat continues.
- The Chat tab still shows its running and finished state, and its completed
  response remains ready when the person chooses to return.
- If a newly persisted Chat resolves to an already-open Chat tab, Workspace
  redirects focus only when the draft itself was active. An unrelated active
  tab remains untouched.

## Upgrade notes

This is an in-place update with no data or permission migration. Registered
Spaces, ordinary files, Chats, Library materials, History, Pi resources,
provider setup, restricted apps, grants, connections, automations, and
App-platform state are preserved.

## Release verification posture

Public release completion requires the exact pushed `v0.4.6` commit to pass
Node 24 TypeScript checks, focused surface-tab regression coverage, the full
test suite, dependency audit, the canonical Electron Builder package smoke,
the Windows release workflow, and the guarded Developer ID-signed, notarized,
and stapled macOS publication lane. The installed 0.4.5 macOS app must then
discover and apply 0.4.6 through the visible frontend updater, preserve an
unrelated active tab during a real Assistant turn, pass installed-bundle
verification, and survive a full quit and cold reopen.
