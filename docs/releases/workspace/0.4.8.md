# Workspace 0.4.8

Workspace 0.4.8 makes everyday navigation quieter, makes Space appearance
easier to get right, and closes a release-blocking readability regression in
Chats.

## Readable, calmer Chats

- User messages now keep the contrast-solved foreground assigned to their
  Space accent in both light and dark themes, including headings, links, and
  inline code.
- Copy is a quiet 24px icon beside the message time. It appears on hover or
  keyboard focus instead of occupying a large action row below every message.
- The Chats navigator foregrounds the selected Space. Matching Chats from other
  Spaces appear afterward as collapsed, minimal groups with counts and
  aggregate activity, and search exposes their matching results.

## A simpler Space switcher

- The duplicate Space tile is gone from the navigation rail, so Files, Chats,
  and History begin at the top.
- The persistent Space-name header now owns switching plus three compact
  actions: **Use existing folder**, **Create new Space**, and **Manage Spaces**.
- The same menu is available on built-in, management, appearance, Extension,
  and restricted-app surfaces. Native app canvases are occluded from the first
  menu animation frame so they cannot cover the menu.
- The current Space stays keyboard-focusable, and the complete menu supports
  deterministic arrow, Home, End, and Escape behavior.

## One-click Looks

- Customize Space now starts with eight curated Looks: Graphite, Harbor,
  Meridian, Verdigris, Orchard, Kiln, Ember, and Foxglove.
- Each Look applies a coordinated primary color, secondary color, and banner
  finish through the existing versioned appearance fields. It does not add a
  theme-package format, execute code, or replace the selected Space icon.
- Every Look passes every audited semantic role in light and dark modes through
  the same WCAG 2.2 AA and APCA-gated resolver used for custom colors.
- Selecting a Look persists immediately on this computer. Fine-tuning any color
  or banner keeps the chosen values and clearly returns the editor to a custom
  state.

## Upgrade notes

This is an in-place update. Registered Spaces, ordinary files, Chats, Library
materials, History, Pi resources, provider setup, appearance settings,
restricted apps, grants, connections, automations, and App-platform state are
preserved.

## Release verification posture

Public release completion requires the exact pushed `v0.4.8` commit to pass
Node 24 TypeScript checks, the full test suite, dependency audit, desktop
preparation, the canonical Electron Builder package smoke, the Windows release
workflow, and the guarded Developer ID-signed, notarized, and stapled macOS
publication lane. The installed 0.4.7 macOS app must discover and apply 0.4.8
through the visible frontend updater, preserve existing state, pass installed
bundle verification, and survive a full quit and cold reopen.
