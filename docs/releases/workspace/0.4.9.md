# Workspace 0.4.9

Workspace 0.4.9 makes everyday Chat navigation faster and more stable, gives
busy tab bars room to breathe, and reduces message chrome so the conversation
stays in focus.

## Stable Chats and calmer navigation

- Opening or switching a Chat no longer lets a stale surface-tab placeholder
  replace its canonical title with **New Chat**.
- Chats and Files now use an immediate, quiet full-row selection treatment
  instead of the former left-edge marker and delayed transition.
- Selected Chat rows expose their current-page state to assistive technology.

## Tabs that scale with the work

- Open tabs adapt their width and spacing as the strip fills. Titles truncate
  inside a stable container, close controls no longer make labels jump, and
  repeated Space icons disappear when horizontal room is scarce.
- The active tab scrolls back into view when it changes or the window narrows.
- **Group by Space** is available from the compact new-Chat menu. When enabled
  and more than one Space has open tabs, the strip shows each Space once and
  keeps that Space's tabs together without changing their durable ownership.
- The grouping preference persists as machine-local interface state and remains
  dormant when only one Space is represented.

## Quieter message furniture

- Redundant **You** and **Assistant** headings are removed from conversation
  messages and live Assistant progress.
- Every completed message now ends with its full sent date and time plus a
  subtle icon-only Copy action.
- User-message footer controls continue to use the contrast-solved on-accent
  roles in both light and dark appearance modes.

## Upgrade notes

This is an in-place update. Registered Spaces, ordinary files, Chats, Library
materials, History, Pi resources, provider setup, appearance settings,
restricted apps, grants, connections, automations, open tabs, and App-platform
state are preserved.

## Release verification posture

Public release completion requires the exact pushed `v0.4.9` commit to pass
Node 24 TypeScript checks, the full test suite, dependency audit, desktop
preparation, the canonical Electron Builder package smoke, the Windows release
workflow, and the guarded Developer ID-signed, notarized, and stapled macOS
publication lane. The installed 0.4.8 macOS app must discover and apply 0.4.9
through the visible frontend updater, preserve existing state, pass installed
bundle verification, and survive a full quit and cold reopen.
